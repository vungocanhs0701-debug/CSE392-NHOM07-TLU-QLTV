# Tên Dự Án Hệ Thống Quản Lý Thư Viện - TLU

**Môn học:** Quản lý dự án Công nghệ thông tin  
**Nhóm thực hiện:** Nhóm 07  
**Giảng viên hướng dẫn:** Đỗ Oanh Cường

## 1. Mục tiêu dự án
- Vận dụng quy trình và các công cụ quản lý dự án CNTT (khởi tạo, lập kế hoạch, thực thi, giám sát và kết thúc dự án) vào một bài toán thực tế.
- Xác định phạm vi (Scope), phân rã công việc (WBS), ước lượng thời gian/chi phí, quản lý rủi ro và phân tích yêu cầu hệ thống (Use Case, User Roles).
- Xây dựng sản phẩm mẫu (Prototype / Ứng dụng hoàn chỉnh) đáp ứng đúng tiến độ và chất lượng đã cam kết.
